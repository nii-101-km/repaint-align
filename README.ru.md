# Repaint Align

Локальный инструмент для совмещения оригинала и репеинта ACE-Step в Audacity. Выделите соответствующие фрагменты, проверьте рассчитанный сдвиг и подтвердите перемещение **целого целевого клипа**. Аудиоданные, темп и длина клипа не меняются.

Основная документация: [English README](README.md). Интерфейс по умолчанию английский; русский выбирается переключателем **Русский**.

## Установка и запуск

Проверено на Ubuntu, **Audacity 3.7.7 через Flatpak**. Нужны Python 3.12+, NumPy, SciPy и браузер. Это отдельное приложение, а не бинарный плагин Audacity.

В Audacity включите **Правка → Параметры → Модули → mod-script-pipe → Включён**, затем перезапустите программу. Модуль позволяет локальным программам управлять редактором; используйте доверенную учётную запись.

```bash
git clone https://github.com/nii-101-km/repaint-align.git
cd repaint-align
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
./run.sh --install-macro
```

Последняя команда устанавливает текстовый макрос `RepaintAlignApply` для штатного Undo/Redo. Сохраните работу и один раз перезапустите Audacity. По умолчанию используется папка макросов Flatpak. Другой путь задаётся `--macro-dir /путь/к/Macros` при установке и запуске.

```bash
./run.sh
```

Откроется локальная страница. При необходимости скопируйте полный адрес из терминала, включая токен после `#`. Остановка — Ctrl+C. Доступны `--no-browser` и `--port 8766`.

## Работа

1. Оставьте открытым только один проект Audacity. Выделите фрагмент оригинала внутри одного клипа, на одной аудиодорожке. Нажмите **Захватить эталон**.
2. Выделите соответствующий фрагмент репеинта в другом клипе. Нажмите **Захватить цель**.
3. Нажмите **Анализировать**. По умолчанию поиск идёт в пределах ±100 мс, сохраняются 5 кандидатов; уточнение — NCC или Huber.
4. Проверьте сдвиг, график и предупреждения. Анализ не перемещает клипы.
5. Нажмите кнопку применения и подтвердите конкретное перемещение. Положительный сдвиг — вправо. Программа проверит положение, хеш аудио целого клипа и позиции остальных клипов.
6. Прослушайте результат. Отмена — штатный Undo / Ctrl+Z в Audacity. После отмены или редактирования захватите фрагменты заново.

Во время операции не редактируйте проект, не запускайте воспроизведение и другие клиенты скриптового канала. Для чтения точных координат программа временно меняет выделение и восстанавливает его. Она не сохраняет проект автоматически.

## Ограничения

- Частота дискретизации и число каналов захваченных дорожек должны совпадать; частота проекта может отличаться. Поддерживаются моно и стерео.
- Слишком короткое выделение для выбранного диапазона отклоняется: длина области сравнения фиксирована для всех сдвигов.
- Huber уточняет окрестности кандидатов NCC, а не выполняет глобальный поиск по Huber. Математический оптимум не гарантирует музыкальную правильность и не исправляет артефакты кодека.
- Проверяются полные клипы, поэтому длинные записи требуют времени и памяти. Временные файлы удаляются после чтения; выделенное аудио остаётся в памяти до очистки, замены или выхода.
- При тайм-ауте **не нажимайте применение повторно**: команда могла выполниться. Проверьте Audacity и перезапустите редактор и инструмент.
- Закрывайте проекты вручную: на проверенной установке был воспроизведён сбой при скриптовом закрытии, поэтому команды `Close`/`Exit` заблокированы.
- Не запускайте служебный макрос вручную. После принудительного завершения процесса повторите `./run.sh --install-macro`, чтобы сбросить его в безопасное состояние.
- Программа использует `mod-script-pipe`, не редактирует `.aup3` и не меняет Beat Grid. Другие версии и сборки Audacity пока не проверены.
